### GET /api/v1/sessions/:id/report

**Auth**: Bearer
**MVP**: Yes

**Purpose**: Get the comprehensive interview report for a completed session (UC-06). Generated by ComprehensiveReportJob.

**Request**

Path param: `id` (session UUID)

**Response**

200 — report ready:
```json
{
  "success": true,
  "data": {
    "report": {
      "id": "uuid",
      "session_id": "uuid",
      "overall_score": 68,
      "skill_scores": {
        "communication": 75,
        "technical_depth": 60,
        "problem_solving": 70
      },
      "strengths": [
        "Clear communication style",
        "Good use of concrete examples in turn 2"
      ],
      "weaknesses": [
        "Technical depth needs improvement — lacked specifics in turn 1",
        "Follow-up answers were too brief"
      ],
      "turn_summaries": [
        {
          "turn_id": "uuid",
          "question_index": 0,
          "question_text": "Tell me about yourself.",
          "overall_score": 72,
          "key_feedback": "Good structure but lacked measurable achievements."
        }
      ],
      "recommendations": [
        "Use the STAR method for behavioral questions.",
        "Prepare 2–3 quantified achievements to reference."
      ],
      "generated_at": "2026-06-05T01:05:00Z"
    }
  }
}
```

200 — report not yet generated:
```json
{ "success": true, "data": { "report": null } }
```
Client should subscribe to `GET /sessions/:id/events` for the `report.ready` SSE event before polling this endpoint.

**Errors**

| Code | Status | When |
|------|--------|------|
| `NOT_FOUND` | 404 | Session does not exist |
| `FORBIDDEN` | 403 | Session belongs to another user |
| `VALIDATION_ERROR` | 422 | Session `status` is not `completed` |

**Notes**

Report is generated by ComprehensiveReportJob (30s timeout, 1 retry — ADR-007). Job is enqueued automatically when the last turn is submitted.

### GET /api/v1/profile

**Auth**: Bearer
**MVP**: Yes

**Purpose**: Get the authenticated user's profile.

**Response**

200:
```json
{
  "success": true,
  "data": {
    "profile": {
      "id": "uuid",
      "email": "user@example.com",
      "full_name": "Nguyen Van A",
      "avatar_url": "https://storage.supabase.co/object/public/avatars/uuid.jpg",
      "preferred_language": "vi",
      "cv_url": "https://storage.supabase.co/object/public/cvs/uuid.pdf",
      "cv_parsed_at": "2026-06-05T00:00:00Z",
      "created_at": "2026-06-05T00:00:00Z"
    }
  }
}
```

`cv_url` and `cv_parsed_at` are `null` if no CV has been uploaded.

**Errors**

| Code | Status | When |
|------|--------|------|
| `UNAUTHORIZED` | 401 | Missing or invalid JWT |

### PUT /api/v1/profile

**Auth**: Bearer
**MVP**: Yes

**Purpose**: Update user profile fields (UC-02).

**Request**

```json
{
  "full_name": "string (optional)",
  "preferred_language": "vi | en (optional)"
}
```

All fields are optional. Omitted fields are not changed.

**Response**

200:
```json
{
  "success": true,
  "data": {
    "profile": {
      "id": "uuid",
      "full_name": "Nguyen Van B",
      "preferred_language": "vi",
      "updated_at": "2026-06-05T00:30:00Z"
    }
  }
}
```

**Errors**

| Code | Status | When |
|------|--------|------|
| `VALIDATION_ERROR` | 422 | `preferred_language` not in `vi | en` |

### POST /api/v1/profile/cv

**Auth**: Bearer
**MVP**: Yes

**Purpose**: Upload a CV in PDF format (UC-02). Server stores in Supabase Storage and parses key information asynchronously.

**Request**

`Content-Type: multipart/form-data`
```
cv: <PDF file>   (max 5 MB)
```

**Response**

200:
```json
{
  "success": true,
  "data": {
    "cv_url": "https://storage.supabase.co/object/public/cvs/uuid.pdf",
    "message": "CV uploaded. Parsing will complete in the background."
  }
}
```

**Errors**

| Code | Status | When |
|------|--------|------|
| `VALIDATION_ERROR` | 422 | File is not PDF, or exceeds 5 MB |

**Notes**

CV parsing is best-effort and async. Parsed data (skills, experience) is stored internally to assist question generation in future sessions. No SSE event is emitted for CV parse completion.

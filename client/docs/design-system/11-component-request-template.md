# Mẫu yêu cầu Component mới (Component Request Template)

Sử dụng mẫu này khi bạn muốn đề xuất một component mới hoặc thay đổi lớn đối với component hiện tại trong Design System.

## 1. Tên Component đề xuất

_[Ví dụ: DataGrid, MultiSelect, DatePicker]_

## 2. Mô tả (Description)

_Component này dùng để làm gì? Vấn đề mà nó giải quyết là gì?_
-

## 3. Tại sao không sử dụng component hiện có?

_Bạn đã kiểm tra các component hiện tại chưa? Tại sao chúng không thể đáp ứng hoặc không thể mở rộng bằng cách thêm prop/variant?_

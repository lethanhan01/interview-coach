# Typography (Kiểu chữ)

Tài liệu này định nghĩa các quy chuẩn **Typography** chuẩn hóa cho hệ thống Interview Coach, bao gồm Font family, Font size scale, Line height và Font weight.

---

## 1. Tổng quan & Mục đích (Overview & Purpose)

Typography đóng vai trò cốt lõi trong việc định hình trải nghiệm đọc, phân cấp thông tin và điều hướng thị giác của người dùng. Hệ thống sử dụng phông chữ **Geist** hiện đại, tối ưu cho giao diện ứng dụng web và thiết bị di động.

- **Sans-serif (`Geist`)**: Phông chữ chủ đạo (`--font-sans`) cho tất cả giao diện người dùng, tiêu đề, văn bản nội dung.
- **Monospace (`Geist Mono`)**: Phông chữ cách đều (`--font-mono`) cho hiển thị mã nguồn, số liệu thống kê, dữ liệu kỹ thuật và timestamp.

## 3. Bảng Tra cứu Tokens Chi tiết (Token Reference)

| Size Name | Tailwind Class | CSS Variable | Rem Value | Pixel Value | Line Height | Trường hợp sử dụng (Use Case) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **xs** | `text-xs` | `--text-xs` | `0.75rem` | `12px` | `1.00rem (16px)` | Helper text, caption, badge, timestamp |
| **sm** | `text-sm` | `--text-sm` | `0.875rem` | `14px` | `1.25rem (20px)` | Input text, button label, table body, card description |
| **base** | `text-base` | `--text-base` | `1.00rem` | `16px` | `1.50rem (24px)` | Body text mặc định, paragraph, modal content |

## 4. Hướng dẫn Sử dụng & Text Hierarchy (Guidelines)

### ✅ Do (Nên làm)
- **Ưu tiên sử dụng Ink Tokens**: Kết hợp font-size với màu chữ phân cấp `text-ink` (chính), `text-ink-muted` (phụ), `text-ink-faint` (nhạt).
- **Tương thích Line Height**: Luôn sử dụng cặp `text-*` chuẩn của Tailwind để tự động nhận đúng `line-height`, tránh bị đè chữ.
- **Thứ tự phân cấp (Heading Hierarchy)**: Đảm bảo thứ tự tiêu đề tuân thủ cấu trúc HTML H1 -> H2 -> H3 -> H4 để hỗ trợ trình đọc màn hình (Screen Reader).
- **Phông monospace đúng nơi**: Chỉ sử dụng `font-mono` cho code snippet, ID hash, chỉ số kỹ thuật hoặc điểm số phỏng vấn.

### ❌ Don't (Không nên làm)
- **Không tùy tiện dùng font size lạ**: Tránh dùng font-size không nằm trong scale như `text-[13px]` hay `text-[17px]` (Tuân thủ Quy tắc 3 trong [UI Conventions](file:///c:/Users/An/Documents/GR1/InterviewCoach/client/stories/foundations/Conventions.mdx)).
- **Không dùng quá nhiều font weight trên 1 màn hình**: Giới hạn tối đa 2-3 độ đậm (`normal`, `semibold`, `bold`) trong cùng một cụm giao diện.

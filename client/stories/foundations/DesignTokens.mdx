# Design Tokens (Kiến trúc Token)

Tài liệu này tổng hợp **Kiến trúc Design Tokens** tiêu chuẩn trong hệ thống Interview Coach. Design Tokens là các giá trị thiết kế nhỏ nhất (như mã màu, khoảng cách, font chữ, độ bo góc) được định nghĩa dưới dạng các biến CSS có tên để dùng chung cho cả Designer và Developer.

---

## 1. Kiến trúc Token trong Tailwind CSS v4

Hệ thống sử dụng **Tailwind CSS v4** với cấu hình `@theme inline` khai báo trực tiếp trong các file CSS tại `client/app/styles/`:

```
[ Primitive Tokens ]      --->  [ Semantic Tokens ]         --->  [ Utility Classes ]
 (Neutral-50, Brand-600)         (--color-primary: ...)            (bg-primary, text-ink-muted)
 (Khai báo tại tokens.css)       (Khai báo tại themes.css)         (Tự động phát sinh bởi Tailwind v4)
```

1. **Primitive Tokens (Token Thô)**: Khai báo tại `tokens.css`. Định nghĩa bảng màu cơ sở (`--color-brand-600`), font chữ (`--font-sans`), bo góc (`--radius-md`), bóng đổ (`--shadow-md`), thời gian chuyển động (`--animate-duration-normal`).
2. **Semantic Tokens (Token Ngữ nghĩa)**: Khai báo tại `themes.css`. Ánh xạ Primitive Tokens sang các tên biến theo mục đích sử dụng, tự động chuyển đổi giữa Light Mode và Dark Mode.
3. **Tailwind v4 Integration**: Thông qua directive `@theme inline`, Tailwind v4 tự động sinh ra các utility classes tương ứng như `bg-primary`, `bg-brand-subtle`, `text-ink-muted`, `border-border-strong`.

## 2. Danh mục CSS Variables & Extended Tokens

### Colors & Themes (Semantic Tokens)
- **Base Semantic**: `--color-background`, `--color-foreground`, `--color-surface`, `--color-card`, `--color-popover`, `--color-primary`, `--color-secondary`, `--color-muted`, `--color-accent`, `--color-destructive`, `--color-success`, `--color-warning`, `--color-info`, `--color-border`, `--color-ring`, `--color-focus`
- **Extended Status Subtle**: `--color-brand-subtle`, `--color-brand-subtle-fg`, `--color-brand-subtle-border`, `--color-success-subtle`, `--color-success-subtle-fg`, `--color-warning-subtle`, `--color-warning-subtle-fg`, `--color-danger-subtle`, `--color-danger-subtle-fg`
- **Text Hierarchy (Ink)**: `--color-ink` (văn bản chính), `--color-ink-muted` (phụ đề/mô tả), `--color-ink-faint` (placeholder/ghi chú nhạt)
- **Surface Elevation**: `--color-surface-raised` (nền nổi bật nhẹ cho container)

### Typography & Fonts
- **Font Families**: `--font-sans` (Geist Sans), `--font-mono` (Geist Mono)
- **Sizes**: `--text-xs` (12px), `--text-sm` (14px), `--text-base` (16px), `--text-lg` (18px), `--text-xl` (20px), `--text-2xl` (24px)
- **Weights**: `--font-weight-normal` (400), `--font-weight-medium` (500), `--font-weight-semibold` (600), `--font-weight-bold` (700)

### Spacing & Layout
- **Layout Tokens**: `--spacing-header-height` (64px / 4rem), `--spacing-sidebar-width` (256px / 16rem), `--spacing-content-max-width` (1280px), `--spacing-page-padding-desktop` (32px), `--spacing-page-padding-mobile` (16px)

### Radius, Shadows & Motion
- **Radius Tokens**: `--radius-none` (0px), `--radius-sm` (2px), `--radius-md` (6px), `--radius-lg` (8px), `--radius-xl` (12px), `--radius-full` (9999px)
- **Shadow Tokens**: `--shadow-xs`, `--shadow-sm`, `--shadow-md`, `--shadow-lg`, `--shadow-popover`, `--shadow-dialog`, `--shadow-focus`
- **Motion Tokens**: `--animate-duration-fast` (150ms), `--animate-duration-normal` (300ms), `--animate-duration-slow` (500ms)
- **Easing Curves**: `--ease-standard`, `--ease-enter`, `--ease-exit`
